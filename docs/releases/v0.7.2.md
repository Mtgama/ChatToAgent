# ChatToAgent v0.7.2 · Local manager pairing fix

Fixes the extension popup reporting “اتصال برقرار نشد” even with a valid local pairing key. The production bundler removed the side-effect-only manager bridge import; the background now registers it explicitly. Regression tests exercise bundling, and release packaging rejects a worker missing the bridge.

اصلاح خطای «اتصال برقرار نشد» در اتصال به مدیر محلی: بخش اتصال در خروجی تولید حذف می‌شد. اکنون ثبت آن صریح انجام می‌شود و بسته‌بندی انتشار نبودن آن را تشخیص می‌دهد.

## Update / به‌روزرسانی

1. Download `ChatToAgent-Chrome-v0.7.2.zip` from Assets and extract it.
2. Replace the files in your existing unpacked-extension folder, then Reload the extension in `chrome://extensions`; alternatively load the new extracted folder and disable the older extension.
3. Refresh chat tabs. Open the Chrome toolbar popup and enter the key copied from the local manager's Connection section.

فایل ZIP نسخهٔ ۰.۷.۲ را استخراج کنید و فایل‌های پوشهٔ افزونهٔ قبلی را جایگزین کنید؛ سپس در `chrome://extensions` افزونه را Reload و تب‌های چت را Refresh کنید. یا پوشهٔ تازه را با Load unpacked بارگذاری و نسخهٔ قبلی را غیرفعال کنید. کلید را از بخش اتصال پنل محلی کپی و در پنجرهٔ آیکون Chrome وارد کنید.

The ZIP contains only the browser extension. An existing running local companion does not need to be reinstalled for this fix. See the bilingual README for fresh installations. `SHA256SUMS.txt` provides the download checksum.

این اصلاح به نصب مجدد مدیر محلی موجود نیاز ندارد. فایل ZIP فقط افزونه است؛ برای نصب تازه راهنمای README و برای بررسی صحت فایل SHA256SUMS.txt را ببینید.
